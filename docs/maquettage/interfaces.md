# Pages
## Listing
- 0- Accueil (non MVP)
- 1- Page de connexion / inscription
- 2- Hub de l'auteur (page d'arrivé après connexion où se trouvent les projets)
- 3- Arborescence du projet
- 4- Arborescence du dossier
- 5- Page du contenu (ici de la note)
- 6- Archives des projets

## But
0 : Présenter l'application et son fonctionnement

1 : S'identifier pour accéder à son espace <br/>
-> Mène au Hub (page 2)

2 : Pouvoir sélectionner le projet sur lequel travailler ou créer un nouveau projet.<br/>
-> si l'utilisateur créé un projet, il est redirigé sur l'arborescence de ce nouveau projet (vide)

3 : Pouvoir naviguer à travers les divers dossiers et notes du projet. Contient également un petit descriptif du projet. Permet aussi de créer un dossire ou une note

4 : Contient un descriptif du dossier pour savoir ce qu'il contient, le but est de naviguer dans le dossier et d'avoir une vue d'ensemble de ce qu'il contient. Peut ajouter un dossier ou une note

5 : Permet de consulter ou de modifier une note via un éditeur de texte riche. La sauvegarde est automatique/

6 : Section où se trouve tout les projets archivé avec leur résumé pour savoir de quoi parle le projet (à l'archivage, proposé d'update le résumé (?)). L'auteur peut "ré-activer" le projet ou le supprimer définitivement
